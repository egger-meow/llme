# 跑完 HugAgent 後，怎麼判讀結果

已完成的 11 人、380 題結果收錄於[第一次實驗報告](experiment-01/README.md)。下文保留全量實驗的分析設計。

第一輪分析審核稿。**主要比較是同一道題的 Graph − Raw，T1 看因果方向是否猜對，T2 看離本人填的分數多遠。** Graph − Flat 是解釋差異的對照。先固定下列分母、圖表與抽樣規則，再開正式模型結果。每個表的資料檔均應記 `run_id`、指標版本、單位、實際人與題數。

### 每項指標怎麼算

| 指標 | 正式定義與分母 | 讀法 |
|---|---|---|
| T1 accuracy | 各域正確題數／全部 T1 題數，再三域平均。356 題中有 3 題金標 A/B，官方接受任一單字母。缺答算錯 | 差值用百分點（pp）。另列二乘二配對表「都對、只 Raw 對、只 Graph 對、都錯」。每域進步幾個百分點 = 100 ×（只 Graph 對 − 只 Raw 對）／該域題數 |
| T2 normalized MAE | 各題的 1–10 絕對誤差除以 2，1–5 保留原始絕對誤差。各域先平均再等權。缺答／不可解析依 pinned scorer 記 6。全 1,386 題 | Graph−Raw 小於 0 代表 Graph 靠近本人答案。0.2 是官方換算尺度上的 0.2，不能解讀成所有原題都少錯 0.2 分 |
| T2 容差命中 | 1–10 誤差不超過 2、1–5 不超過 1，各域分母為全部 T2 題。缺答未命中 | 跟作者比較的輔助欄。容差內再更接近真人仍可能只在 MAE 看到 |
| T2 方向 | 同人同域把自己的基準題預測和其他 opinion 預測配對。各域為 0.3 ×「有無改變」命中率 + 0.7 ×「雙方都改變時，方向相同」比例。後項無可計配對時 scorer 給 0；整域沒有有效配對時該域缺值 | 最多 179 對，含 92 個假設情境、87 個經驗／感受。報各域可解析配對數、其中雙方改變數、實際納入域，以及各臂共同可解析配對的補充表。稱為官方方向分，對異質題意保持分列 |
| 格式與服務失敗 | 每組全 1,742 格，列終端失敗、不可解析、可解析但格式不符、超量尺、建圖失敗波及題數與實際回覆數，保留原因旗標。官方 parser 可能從長句取到字母／首個數字 | 主要表沿用官方 parser，越界值照原值評分，不夾限。另報整句剛好一個合法選項或量尺內整數的比例與嚴格解析敏感度。全量作業若因額度停在中途，先標未完成 |

三個臂各保存 `{item_id, response}` 的 1,742 列（終端失敗為 null），先檢查重複／未知／缺列，再用原版 `--score` 計算。先前跑過的固定／隨機列是評分器的回歸檢查。發表時另列原論文分數作背景，明記模型版本、執行次數及來源，方法比較採用本次同條件 Raw。

## 表二．同一道題換輸入，真的改善了多少

| 比較 | T1 差（pp）與 95% CI | T2 差（五分尺度）與 95% CI | 能檢驗的解釋 |
|---|---|---|---|
| Graph − Raw（主要） | 待測；正值有利 Graph | 待測；負值有利 Graph | 從 QA 抽一份有引文的圖，再讓模型讀圖的整體效益 |
| Graph − Flat（次要） | 待測 | 待測 | 同一批已抽取的主張和引文，顯式連線相對於展開成句的呈現效果 |
| Flat − Raw（補充） | 待測 | 待測 | 抽取整理後改讀句子的整體效益 |

- **點估計。** 每道題的臂別配對，保持表一的域內題目加權與三域等權。T1 每域有題的人數是 43、47、51，T2 各域均 54。另做「每人等權」敏感度，每人先在各有題的域內取平均，再將這些域等權平均，最後跨人等權平均。列出每人有效域數；它回答典型受訪者會否得益。
- **區間。** 建議凍結 bootstrap seed 20261123，從 54 人有放回抽 54 人 5,000 次，保留該人的所有域、題及三組回答。每次重算兩種方法及差，再取 2.5、97.5 百分位。重複抽到的人保留複本權重；重新呼叫以 ID 建字典的 scorer 時給複本不同人／題鍵。必要域分母為零的重抽值列缺值並記有效重抽數。Rank 同理抽其 52 位有配對的人。1,742 題、994 對理由都不能當作彼此獨立的受試者。
- **下結論。** 兩個主要終點各有方向與單位，逐項報點估與區間，無「任一格過線即整體成功」的規則。T1 進步而 T2 退步就報此取捨。區間跨零表示資料容許兩個方向；若想說等效或非劣，需要開跑前約定最小有意義差距。次要切片用於定位與產生下輪假設。
- **變異來源。** 固定模型抽取一次、每題每臂預測一次的區間反映受訪者抽樣變異。若經費允許，預先指定子集或全量，先固定圖重跑預測，再對相同 scopes 獨立重建圖、重跑預測，分報兩種變異、重複次數與費用，不把 seed 當新受訪者。

| 同人理由排序 Rank | 已有同人同域同題幹的兩個不同理由。按兩個整數之差記左高／相同／右高，與 `gold_sign` 比。全量 52 人、994 對，407 有高低、587 同分 | 報三類混淆表、全 994 對命中率、407 對嚴格高低命中率、587 對同分召回與各臂預測同分率。預測同分在嚴格高低子集算錯。全猜同分已有 59.1%，整體數字不能單獨讀 |

Rank 的缺答、越界或格式錯誤要可定位。建議此**補充**指標只用整句合法的量尺內整數判方向；缺任一端就標無有效預測，固定全對數分母計未命中，同時報有效覆蓋及三臂都有效子集。能檢驗的是本人對兩理由的影響力排序；若要驗證在代價下的真實選擇，須取得二選一行為。跨情境對完全相同兩理由，現有彙查僅 19 組、嚴格翻轉 0 組，單靠它無法評估 Tree 偵測翻轉的敏感度。[配對定義與跨情境限制](HugAgent-54-Research-Design.md)

### 成本帳要算兩次

設某一份訪談建圖成本為 B，第 i 題用 Raw、Graph、Flat 作答的實際成本分別為 Rᵢ、Gᵢ、Fᵢ。若部署 Graph，這 n 題要付 **B + ΣGᵢ**，每題平均再除以 n；Raw 為 **ΣRᵢ**。Graph 真正比較省的條件是 **Σ(Rᵢ − Gᵢ) > B**。若每題平均連預測部分都無節省，就沒有可推定的損益兩平點。Flat 以 Fᵢ 代換。若畫標準化重用次數曲線，固定題序或平均單題成本，標清哪些是觀察值、哪些是情境估算。

實際研究一次跑兩個渲染只付一次 B，所以**研究總帳**為 ΣB + ΣRᵢ + ΣGᵢ + ΣFᵢ，另記失敗與重試費用（若已計入各項則不再加）。若是比較各方法單獨部署，Graph 和 Flat 各自都要負擔建圖成本。全資料 460 份 scope 中 300 份只回答一題；另 160 份合計用於 1,442 題，單份最多 23 題。前者代表初次提問的成本，後者才有實際的重用機會。[逐題與 scope 索引](../../ref/HugAgent/prepared/items.csv)

## 怎麼知道輸在「圖」的哪一段

預先鎖抽樣 seed 和人力。建議先做下列兩份小樣本，兩份各有自己的分母。

1. **盲審圖的忠實度。** 每域從建成功的 scopes 均勻抽 10 份（共 30 份，列涵蓋人數；建圖失敗率另以全 460 算）。每份均勻抽至多 2 個 claim，由兩位評者獨立看原話判有支持／部分／缺支持／資訊不足。另從每份原訪談均勻抽 2 段 QA，先記其中可提取的重要判斷，再查圖有無保留。分開報有據主張比例、可提取判斷的保留率、兩人原始一致率與分歧類型。抽到零主張仍做 QA 方向的檢查。若只有一位評者，標單人試標並公布可稽核的規準。
2. **盲看分歧題，再揭開結果。** 每個任務預抽「Graph 較好、Raw 較好、同分」各 5 題，可用不足就全取，最多 30 題；T2 按同題誤差，T1 按命中。抽樣程式知道分歧格，人審先隱藏得分、臂名及真人答案，記可見 QA、快照與渲染是否忠實，再開答案。標記漏抽、錯置本人與一般人、條件放寬、方向／程度錯、渲染遺失、證據在卻答錯、資料不足／原因未明。記重疊 scope 與參與者。這是刻意抽的錯例與同答對照，其類別比例不能直接外推成全量錯誤率。

逐題頁應能從圖表進入某題，並列三組實際讀到的英文、回覆、距離或對錯。點主張可見引文、條件、例外及當時的提交。若人工可證原圖已誤寫主體，就能定位到抽取；若文字完整而模型仍答錯，最多能說在此輸入下作答失敗。判斷「模型依賴了哪條邊」需要額外干預。

## 哪種結果值得開下一輪

| 觀察 | 可說的事 | 最能改變判斷的下一步 |
|---|---|---|
| Graph 勝 Raw，也勝 Flat | 這個模型與資料上，整套方法與顯式表示都有收益 | 看逐人分布與成本；固定條件用第二個模型確認可移植性 |
| Graph、Flat 均勝 Raw，兩者差的區間很寬 | 整理訪談可能有益；顯式連線的增益仍不確定 | 提高比較精度，或加入等預算的獨立文字摘要 |
| Graph 勝 Flat，Raw 最好 | 顯式編碼幫助模型讀已抽出的內容，但目前管線仍輸直接讀原話 | 從原 QA 回查漏掉的問句、限定詞、語氣及主體 |
| T1 改善，T2 理由分或特定人群退步 | 保存方向與保存程度是兩件可分開驗證的事 | 檢查程度詞、判斷對象及每人題數；如欲改規則另標探索版本 |
| 多題需要的父／子規則都在，卻在條件切換時答錯 | 有理由單獨測 Tree 路由 | 先盲標適用規則與可判定案例數，再固定規則、token／工具預算，比平面匹配與樹狀讀取。另用合成資料覆蓋兄弟交集、未知與覆寫 |
| 要知道能否跨議題保留個人線索 | 第一輪域內差答不了這題 | 同人固定目標題，切換至指定來源域。三個方向分報「跨域−域內」與「兩臂掉分差」；遷移的是哪條規則仍需核對來源 |
