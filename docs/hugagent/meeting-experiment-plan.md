# 本週 meeting｜把同一人的訪談整理成圖，能更準地預測他的回答嗎？

**本週帶給老師的進度**是已可核對的真人資料、一個改變實驗設計的洩漏發現，以及能區分「整理訪談」和「顯式連線」的三組比較。以下是建議的八分鐘講法，每段對應一張投影片。實驗方法與分析都仍是審核稿。

### 1．為什麼測這件事（50 秒）

**畫面**放一段問答、同一個人的一個新問題，中間留兩條路「直接讀」和「整理成圖再讀」。

**可以這樣講**：「我想做的是 LLM + me。假如模型真的從我的話學到我怎麼判斷，我希望它遇到新問題時猜得更接近，也說得清楚它把我哪句話理解成什麼。這輪把第一件事變成可逐題計分的實驗，同時保留能查第二件事的紀錄。」W7 的具體出發點是同一個選擇能支持多廣的取捨判斷；W8 提議先把錯誤追到原句，再決定是否需要情境路由。[W7 第 6–9 頁](../../meetings/W7.pdf#page=6) · [W8 第 9–11 頁](../../meetings/w8.pdf#page=9)

### 2．用 P07 講清楚什麼是考題（75 秒）

| 公共監控 | 模型的參考資料 | 模型這次要交什麼 |
|---|---|---|
| T1-0009 | P07 的背景和這一題允許的 **19 段** chatbot 訪談 | 他認為執法問責會提高還是降低人們對監控的支持？答一個字母 |
| T2-0015 | 同一人的背景和這一題允許的 **20 段** chatbot 訪談 | 影像只存 48 小時、只在事件後查看時，**P07 自己**會給幾分支持？答 1–10 的一個整數 |

**指著 19 和 20 講**：「兩題都在考模型。T1 的對照答案來自被遮住的訪談問答，T2 的對照答案來自本人填過的問卷。T2 的訪談多出來的那一段，剛好說出 T1 要猜的關係。我如果先替 P07 建一張完整圖，再拿它考 T1，就會讓模型提早看過答案。」全量逐字比對，T1 在自己資料中命中 0／356，在同人同域 T2 命中 271／356。這是資料整理後才確定的規模。[W7 第 3 頁](../../meetings/W7.pdf#page=3) · [逐題證據與資料驗收](prepared-data.md)

### 4．三組到底差在哪裡（95 秒）

**畫面**畫成一次分叉，再分叉。原 QA 可以直接給 Raw，也可以先交給建圖模型；建好的**同一個快照**分別排成 Graph 和 Flat 給同一個預測模型。

| 逐步指畫面 | 一句講完 |
|---|---|
| Raw 對 Graph | 「先整理成有根據的圖，整套做法能否比模型直接讀本人原話更準？」 |
| Graph 對 Flat | 「同樣抽到這些話、同樣附這些引文，如果改寫成普通句子，成績還有差嗎？」 |
| 點開互動樹 | 「例如 P46 認為提高開發密度通常讓交通更塞；若大眾運輸好搭而且便宜，他預期交通持平。這條例外改的是他對交通的判斷，不能直接寫成他支持開發。」 |

**展示操作**：開 P46 → 都市分區 → 提高開發密度 → 大眾運輸好搭且便宜 → 點「取代」箭頭。說明研究者可以沿樹追哪條判斷被改了。第一輪模型拿到完整英文表示；往後才另外測「讓它按題走樹」是否有額外效益。這個案例是依原話整理的設計示範。[可操作的樹與圖](../tree-review/index.html) · [模型接口草案](experiment-interfaces.md)

### 6．哪個結果會真的改變下一步（90 秒）

- **Graph 和 Flat 都勝過 Raw。** 下一個問題是整理後的文字是否已足夠。先看兩者差多少、區間多寬，以及建圖成本。460 份中有 300 份只用在一題，不能預設建圖一定划算。
- **Raw 勝。** 打開同一道題，查模型是否把「他認為一般人怎麼想」寫成「他本人怎麼選」，或把「非常強」與「稍微」都畫成同一支箭頭。
- **圖上已有父規則與例外，模型卻常套錯。** 這才用到 W8 提出的下一個對照：固定同一批規則，比平面規則與樹狀讀取。真人資料中，同一對同措辭理由跨情境可比的只有 19 組，嚴格反轉 0 組。測 Tree 還要另外標註哪些規則確實適用。[W8 第 10 頁](../../meetings/w8.pdf#page=10) · [配對統計](HugAgent-54-Research-Design.md)

收尾可問老師兩件事：**這輪的論文主張，先落在「怎樣呈現同一人的訪談比較準」是否足夠？如果要主張「學到個人獨有線索」，是否應把換人／無訪談對照提早？** 以及 **只有原話明說覆寫時才送給模型，會不會過度保守？可否把模型推論的候選例外留給獨立消融？** 前一題決定要跑幾組，後一題決定 Graph 和 Flat 裡真正有什麼。模型與費用上限可在研究範圍定下後鎖定。
