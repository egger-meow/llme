# 第一輪接 key 前的架構驗收

這份紀錄對應 W7 的「本人如何取捨」、W8 的情境與例外設計，以及本輪核定的同模型、同題、同證據比較。正式結果要回答的是換成這款英文 Graph 表示後，預測同一人的回答改善多少。

| 對照條件 | 實作與離線驗收 |
|---|---|
| 資料來源與洩漏 | 指定 fork、固定版本、六個真人檔與官方 scorer 雜湊。prepare 逐題重建官方 Raw。builder 只收當題可見的有序 QA；同一人的不同 evidence scope 分開建圖 |
| 建圖、條件與例外 | 一次完整提議，逐條保存有父雜湊的操作。主張區分持有者、判斷對象、概念、方向／結果、條件、明說／推論、支持與反證。明示例外可指向較早的同一判斷。語義是否忠實由盲審評估 |
| LLM 讀取與重播 | Graph／Flat 讀同一份快照。產生評分報告前比對模型收到的訊息、原始回答、拒絕原因、操作鏈和渲染。Raw 獨立續跑，失敗保留在分母 |
| 設定、容量與預算 | 凍結模型、endpoint、模板、解碼、Python、程式雜湊與計價設定；保存初始 Git 狀態。建圖後先預檢全部預測輸入。每次生成前以最高單價和最大輸出預留，未知送達須明示重送，服務端回報版本改變會中止 |
| 指標與不確定性 | T1 正確率、T2 五分尺度誤差照官方三域等權。三組使用同題。Rank 分全體、有高低及同分；按人配對重抽 5,000 次，另有混淆表及三組皆有效的子集 |
| 成本 | scope_amortization.csv 列獨立部署各方法的冷啟動與每題攤提；research_costs.csv 列實際研究共用建圖的總帳。金額按填入的費率上限估算，未取得用量保留空值。generation_attempts.csv 含送達未知及失敗的預留額。帳單需日後向服務商核對 |
| 盲審與結果 | 畫面可由 Graph 較準／Raw 較準的題目追到實際輸入，逐條查原話。評者拿 reviewer 資料夾，研究者保留解盲表。會議頁含官方基準、四類 T2 與逐人圖。每個圖上數值有分母和逐題來源 |

## 離線演練結果

全量混合回覆演練含 54 人、1,742 題、460 個建圖終態。刻意拒絕一份圖，仍保留三組合計 5,226 格作答及 2,982 筆理由配對結果。此次兩次獨立評分的 34 份產物逐檔雜湊一致。會議圖上 120 筆數值均從逐題資料另外重算；九個理由排序差值都核對命中數與配對分母。Edge 實測由報告開啟會議頁並載入三張 SVG。所有三組數字均為合成回覆的驗收用途。

## 正式啟動與解讀邊界

1. 將範本複製為本機費率設定，確認實際模型 ID、最高適用單價、容量與研究預算。key 只讀環境變數。以新的正式 run 名稱和一個生成請求額度開機，查看模型實際版本、結束原因、用量、建圖引文和重播。確認相容後用同名續跑。[啟動指令](../../README.md)
2. 已看過的真題包含研究設計六筆樣本、W7 的 P07 以及情境樹示範 P46；完整資料仍照官方評分。不得依這一輪真人分數修改方法後再把同批結果稱為事前驗證。[六筆題號](HugAgent-54-Research-Design.md) · [已公開的例題](meeting-brief.md)
3. 本輪採批次提議、明示例外與完整表示。多輪工具修圖、本人實際更正、按題走 Tree、跨域遷移、換人對照都有各自的研究問題。現有樹是研究者可操作的設計示範。HugAgent 未提供本人審過模型主張的標籤。[互動樹](../tree-review/index.html)
4. 離線驗收涵蓋配置、請求建構、容量和預算邊界與故障流程。模型目前能否接受這組設定、真實生成品質、費率與實際帳單、人工評者間一致性，須在接 key 或取得評分後實測。受訪者抽樣區間只涵蓋此一組固定回覆。
